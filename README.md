# Automated-Academic-Program-Guide
Sebuah chatbot yang dibuat sebagai asisten kemahasiswaan yang diperuntukan untuk menjawab pertanyaan dari Ormawa seputar program kemahasiswaan seperti PPK Ormawa yang diselenggarakan oleh Kementerian Pendidikan Tinggi, Sains, dan Teknologi (Kemdiktisaintek) Republik Indonesia.
